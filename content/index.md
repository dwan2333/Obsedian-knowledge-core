# Knowledge Core

Welcome to my Obsidian vault, published as a website via [Quartz](https://quartz.jzhao.xyz).

This vault is organized as a hub-and-spoke knowledge system, with main topic areas branching into companion notes and interactive demos.

## Sections

- **[Mathematics](Mathematics/)** — Introduction to Probability (Blitzstein & Hwang), quadratic formulas, worked examples
- **[Git and Github](Git%20and%20Github/)** — Version control concepts, branching, syncing, collaboration workflows
- **[Finance](Finance/)** — Markets, instruments, frameworks
- **[Learning AI from TOP to Bottom](Learning%20AI%20from%20TOP%20to%20Bottom/)** — AI/ML notes
- **[Poker](Poker/)** — Strategy, hand analysis, study notes

## Features available on this site

- **Wikilink and markdown navigation** — click any link to jump between notes
- **Backlinks panel** — see which other notes reference the current one
- **Graph view** — visualize the structure of the entire vault
- **Full-text search** — `Ctrl/Cmd + K` opens search
- **Interactive HTML demos** — embedded walkthroughs (e.g. lattice paths, counting functions, Casino Superdeck) render as live pages
- **LaTeX math** — formulas render via KaTeX
- **Mermaid diagrams** — flowcharts and sequence diagrams render natively
- **Dark/light mode toggle** — switch via the icon in the header
