— On the formulas

Part (a). A function from A to B is just a list of n choices, one per element of A — and each choice is freely picked from B's m options, independently of all the others. Multiplying gives:

mn  total functions A → B

Part (b). A one-to-one function uses each B-element at most once, so the choices stop being independent. After picking f(a₁), only m−1 elements of B remain available; after picking f(a₂), only m−2; and so on, for n picks total:

m · (m−1) · (m−2) · · · (m−n+1)
= m! / (m−n)! = P(m, n), the falling factorial

If n > m, by the pigeonhole principle some B-element must be hit twice, so no one-to-one function exists — the count is 0. Try setting n = 3, m = 2 in the panel above to see the (b) side go empty.
